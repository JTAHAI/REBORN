# North Berwick reconstruction references

This directory preserves the open reference photographs used to create the Build 009
North Berwick facade atlas and a contact sheet for review. The photographs are not Google
Street View captures. Exact author, license, date, and Wikimedia Commons source-page data
are recorded in `ATLAS_SOURCE_MANIFEST.json` and `SELECTED_ATTRIBUTION.md`.

The photographs are references for authored landmark massing and facade treatment. They
do not establish that unrelated procedural houses or modern commercial campuses are exact.
