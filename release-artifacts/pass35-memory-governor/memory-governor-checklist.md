# Memory Governor manual checklist

1. Open `/play/` and start Free Drive.
2. Press `M` or tap MEMORY.
3. Confirm the report shows `memoryGovernor: true`.
4. Drive through a dense town area on desktop and mobile.
5. Watch memory mode, score, canvas pixels, static objects and buffer allocations.
6. Export the JSON report and attach it to a manual feedback issue if needed.

No report is uploaded automatically. This checklist is not physical-device memory certification.
