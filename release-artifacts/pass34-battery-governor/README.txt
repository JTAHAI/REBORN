# 99½ REBORN — Pass 34 / Build 043 Battery Governor

Build 043 adds an idle-aware Battery Governor on top of Thermal Governor, Frame Pacer and Render Optimizer.

Deploy the contents of `REBORN-PASS-34-BATTERY-GOVERNOR-FULL-WEBSITE.zip` to the existing static host. The standalone ZIP is `REBORN-PASS-34-BATTERY-GOVERNOR-Standalone.zip`.

In game, press `B` or the BATTERY button to open the local report overlay. Nothing is uploaded.

This package is not deployed, not store-submitted and not physical-device FPS or battery certification.
